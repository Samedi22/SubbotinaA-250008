## Лабораторная работа №1 – Ввод/вывод, базовые условия и создание графического интерфейса
Приложение представляет собой интерактивную графическую систему на базе библиотеки Tkinter, разделенную на три независимых модуля (задачи) с боковой навигационной панелью, анимацией, поддержкой горячих клавиш и адаптивным дизайном.  

**Краткое описание реализованных задач:**  
- **Задание 1.1 (Площадь треугольника):**
Расчет площади произвольного треугольника по трем введенным сторонам с использованием формулы Герона:
  
$$S = \sqrt{p\left(p-a\right)\left(p-b\right)\left(p-c\right)}$$   

где полупериметр p=\frac{a+b+c}{2}. Программа выполняет проверку на возможность существования треугольника (неравенство треугольника) и валидацию корректности ввода числовых значений. 
- **Задание 1.2 (Конвертер расстояний):**
Универсальный инструмент перевода физических величин длины между километрами, метрами, сантиметрами, миллиметрами, милями и ярдами по встроенным коэффициентам пересчета. Поддерживает вещественные значения.  
- **Задание 1.3 (Високосный год):**
Проверка года на високосность по правилам Григорианского календаря (год високосный, если он делится на 400 или делится на 4, но не на 100). Наглядно визуализирует логические правила в виде плиточного интерфейса.  

## Среда разработки
Язык программирования: Python 3.10+  

Использованные библиотеки:
- tkinter, tkinter.ttk — проектирование интерфейса пользователя и стилизация элементов;
- math — извлечение квадратных корней и тригонометрические расчеты для анимации;
- datetime — работа с системным временем для встроенных часов;
- ctypes (опционально) — интеграция темной темы заголовка окна с API Windows (DWM).

Среда разработки (IDE): [Например: PyCharm / VS Code / IDLE]

## Инструкция по работе с программой
Запуск: Запустите скрипт laboratornya1.py через терминал (python laboratornya1.py) или среду разработки.  

**Навигация:**

- Переключение между вкладками осуществляется двумя способами:
	- Нажатием на элементы бокового левого меню мышью.
	- Использованием быстрых горячих клавиш: Ctrl+1 (Треугольник), Ctrl+2 (Конвертер), Ctrl+3 (Високосный год).
- Ввод данных: В поля ввода допускается вводить числа с плавающей точкой. Программа автоматически адаптирует как точку (.), так и запятую (,) в качестве разделителя. Нажмите клавишу Enter в любом поле ввода или кнопку «Вычислить» («Конвертировать» / «Проверить») на экране для запуска расчёта.
- Очистка данных: Кнопка «Очистить» возвращает интерфейс к исходному состоянию и сбрасывает фокус.
- Индикация состояний: В нижнем левом углу расположена статусная строка. При возникновении ошибок ввода (символы, пустые поля, невозможные физические значения) зажигается красный маркер ошибки. При успешном выполнении загорается зеленый маркер.
